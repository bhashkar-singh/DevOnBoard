🚀 Interactive Task Walkthrough: Authentication & Token Flow

Follow one incoming authentication request from the frontend form to database token generation. Understand the RBAC permissions and session cache.

Step 1: Frontend Form Submission frontend/js/app.js
The browser dispatches POST /api/auth/login with email and password. Token is saved in localStorage.setItem('devonboard_token').
Step 2: Backend Controller & DB Validation backend/app.py
The endpoint validates user credentials against SQLite schema users table, checks password hash, and produces an active session token.
Step 3: RBAC & Personalization Hook backend/db.py
User role (mentee, mentor, admin) is decoded, unlocking custom permissions and loading matched mentors.
